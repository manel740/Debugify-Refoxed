## About this Port

This is the **NeoForge 1.21.1** port of the original [Debugify](https://github.com/isXander/Debugify) mod created by [isXander](https://github.com/isXander). It retains all the original bug fixes and configurations, adapted to work seamlessly with the NeoForge mod loader.

## Configuration Menu

You can configure which bug fixes are enabled or disabled in-game.

1. Open the **Mods** list from the main menu.
2. Select **Debugify Refoxed**.
3. Click the **Config** button.

If you prefer editing files manually, the configuration file is located at:

`.minecraft/config/debugify.json`

## Client, or Server?

Debugify Refoxed includes many fixes for both the client and the server (all server fixes also apply to the client). You should definitely use it on both.

## Can I include this in my modpack?

Yes, of course. The constant updates may be exhausting to maintain, so there is a config option that defaults new bug fixes to off until you get round to looking at them.
